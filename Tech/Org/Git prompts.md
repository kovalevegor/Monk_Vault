### Таблица основных команд Git

##### Основные команды для начала работы

| Команда                   | Описание                                                      |
| ------------------------- | ------------------------------------------------------------- |
| `git init`                | Инициализирует новый репозиторий Git в текущей папке          |
| `git clone <url>`         | Клонирует удаленный репозиторий на локальный компьютер        |
| `git status`              | Показывает текущее состояние репозитория и измененные файлы   |
| `git add <file>`          | Добавляет файл в индекс (staging area) для следующего коммита |
| `git add .`               | Добавляет все измененные файлы в индекс                       |
| `git commit -m "message"` | Создает коммит с добавленными изменениями                     |
| `git log`                 | Показывает историю коммитов текущей ветки                     |

---
##### Работа с ветками

| Команда                                  | Описание                                  |
| ---------------------------------------- | ----------------------------------------- |
| `git branch`                             | Показывает список всех локальных веток    |
| `git branch <имя-ветки>`                 | Создает новую ветку                       |
| `git checkout <ветка>`                   | Переключается на указанную ветку          |
| `git checkout -b <новая-ветка>`          | Создает и переключается на новую ветку    |
| `git merge <ветка>`                      | Сливает указанную ветку с текущей         |
| `git branch -d <ветка>`                  | Удаляет локальную ветку                   |
| `git branch -m <старое-имя> <новое-имя>` | Переименовывает ветку                     |
| `git push origin --delete <имя-ветки>`   | Удаляет ветку на удаленном репозитории    |
| `git switch -c new-branch`               | Создание + переключение (новый синтаксис) |

---
##### Работа с удаленным репозиторием

| Команда | Описание |
|---------|-----------|
| `git push -u origin <ветка>` | Отправляет ветку на удаленный репозиторий |
| `git push` | Отправляет коммиты в удаленную ветку (после -u) |
| `git pull` | Забирает изменения из удаленной ветки и сливает с локальной |
| `git fetch` | Забирает изменения из удаленного репозитория без слияния |
| `git remote -v` | Показывает список удаленных репозиториев |

---
##### Отмена изменений

| Команда                    | Описание                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `git checkout -- <файл>`   | Отменяет изменения в файле (до последнего коммита)                                    |
| `git reset --hard`         | Отменяет все незакоммиченные изменения                                                |
| `git stash`                | Временно сохраняет незакоммиченные изменения                                          |
| `git stash pop`            | Возвращает временно сохраненные изменения                                             |
| `git reset --soft HEAD~1`  | Отменить последний коммит, сохранив изменения в файлах (unstaged)                     |
| `git reset --mixed HEAD~1` | Отменить последний коммит и убрать изменения из индекса (staged), оставив их в файлах |
| `git reset --hard HEAD~1`  | Полностью отменить последний коммит вместе с изменениями в файлах                     |

---
##### Просмотр информации

| Команда | Описание |
|---------|-----------|
| `git diff` | Показывает различия между незакоммиченными изменениями |
| `git show <коммит>` | Показывает информацию о конкретном коммите |
| `git ls-tree -r <ветка>` | Показывает список файлов в ветке |

---
##### Полезные команды

| Команда | Описание |
|---------|-----------|
| `git rm <файл>` | Удаляет файл из индекса и файловой системы |
| `git remote add origin <url>` | Добавляет удаленный репозиторий |
| `git branch --set-upstream-to=origin/<ветка>` | Устанавливает связь с удаленной веткой |
