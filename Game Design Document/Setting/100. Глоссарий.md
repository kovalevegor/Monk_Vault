## 1. Основы мироздания: закон и природа реальности

| Термин | Краткое значение |
| :--- | :--- |
| **Карма** | Действие и его след. Намеренный поступок оставляет отпечаток, определяющий будущий опыт. Не «судьба», а «инерция поступков». |
| **Пунья / Папа** | Заслуга / грех. Два независимых «счёта» внутри кармического механизма, созревающих по отдельности. |
| **Джива** | Душа, индивидуальное живое начало (джайнский термин). То, к чему «прилипает» кармическая материя. |
| **Виджняна** | Поток сознания. Непрерывный процесс осознавания, переходящий между жизнями (свеча зажигает свечу). |
| **Кашая** | Страсти (гнев, гордость, жадность, обман). «Клей», удерживающий кармическую материю на дживе. |
| **Karma-pudgala** | Кармическая материя. Тонкая субстанция с измеримыми параметрами (тип, длительность, интенсивность). |
| **Випака** | Созревание. Момент превращения кармического следа в реальное последствие (рождение, обстоятельства). |
| **Анатта / Анатман** | «Не-я». Доктрина об отсутствии неизменного «я». Личность — это поток, а не точка. |
| **Анитья** | Непостоянство. Фундаментальное свойство всего составного: всё распадается. |

## 2. Практика, статус и община

| Термин | Краткое значение |
| :--- | :--- |
| **Дхарма** | Учение Будды; закон, порядок вещей, «как всё работает». |
| **Сангха** | Община практикующих (монахи и миряне), следующие Дхарме. |
| **Бодхисаттва** | «Существо пробуждения». Тот, кто отказался от личного освобождения (нирваны) ради спасения всех живых существ. |
| **Сиддхи** | Сверхспособности, обретаемые через практику; буддийская «магия» в сеттинге. |
| **Тулку** | Перерожденец. Признанное новое рождение конкретного учителя. |
| **Ринпоче** | «Драгоценный». Почётный титул для высоких учителей и лам. |

## 3. Смерть, перерождение и переходы

| Термин | Краткое значение |
| :--- | :--- |
| **Пхова** ('pho ba) | Перенос сознания. Практика направления виджняны в момент смерти. Легитимная цель — «чистые земли» (вверх); чёрные монахи направляют горизонтально — в чужое тело. |
| **Бардо** | Промежуток. Состояние «зала ожидания» между смертью и следующим рождением. |

## 4. Ритуалы, предметы и священные объекты

| Термин | Краткое значение |
| :--- | :--- |
| **Тханка** | Ритуальная живопись на ткани. В сеттинге обладает реальной силой. |
| **Мала** | Чётки (традиционно 108 бусин). |
| **Ваджра / Дордже** | «Алмазный скипетр». Ритуальное оружие, символ несокрушимости духа. |
| **Дунгчен** | Длинная ритуальная труба. |
| **Чам** | Ритуальный танец в масках. В сеттинге служит для призыва реальных защитных существ. |

## 5. Традиция Бон и духи

| Термин | Краткое значение |
| :--- | :--- |
| **Бон** | Добуддийская традиция. Работает с духами территорий через договоры. Карма — взаимное обязательство существ, а не безличный закон. |
| **Са-дак** | Духи земли (Бон). |
| **Лу / Наги** | Духи воды. Змееподобные хранители, чувствительные к моральной нечистоте. |
| **Ньян** | Духи скал и деревьев (Бон). |
| **Цен** | Воинственные духи гор (Бон). |

## 6. Бытовые и организационные термины

| Термин | Краткое значение |
| :--- | :--- |
| **Гомпа** | Монастырь-крепость. В сеттинге — два крупных региональных центра (Восточный и Западный). |
| **Менкханг** | Лечебный монастырь. Медицина через диагностику кармического отпечатка. |
| **Цхонпа** | Торговая гильдия. «Серая зона» между Буддизмом и Бон, имеющая внешние связи. |
| **Лосар** | Новый год по лунному календарю. |
| **Монлам Ченмо** | Великий молитвенный фестиваль. |
| **Цампа** | Мука из обжаренного ячменя, основа питания. |
| **Прана** | Жизненная сила. «Клей» между кармической материей и физическим телом. Потеря праны ослабляет привязку кармы. |
