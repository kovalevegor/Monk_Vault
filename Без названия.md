Полная инструкция от точки «Этап 3 завершён» (созданы говорящие NPC) до готового квеста, с учётом интеграции вашей системы интеракции. Эта версия дополнительно включает создание объектов (дерево, тело Лобсанга, точки, актор состояния), которых в варианте «после этапа 4» уже предполагалось наличие.

Перед началом — два повторяющихся паттерна и две вставки чтения состояния; держите их под рукой.

**Блок P (диалог по инициативе игрока):**

```
[вход] → On Notify From Actor (Identity=<id>, Notify=<knock>)
            ├─ Success  → Notify Actor (Identity=<id>, Notify=<строка.NN>)
            └─ Completed → [следующий]
```

**Блок G (шаг сцены по инициативе графа):**

```
[вход] → Notify Actor (Identity=<актор>, Notify=<команда>)
       → On Notify From Actor (Identity=<актор>, Notify=<команда.Done>)
            └─ Success → [следующий]
```

**Чтение «есть ли предмет»:** `Get Player Pawn → Get Component by Class (AC_InteractionComponent) → Get CollectedItems → Has Tag (<Item-тег>)`.  
**Чтение флагов квеста:** `Get All Actors Of Class (BP_QuestState) → Get (index 0) → Get bSongKnown / bTextCopied`.

> **Что должно быть после Этапа 3:** все теги (включая `Monk.Item.*`, `Monk.State.*`, `Monk.Knowledge.*`, `Monk.System.Director.01`); говорящие NPC на `BP_NPC_Base` (Лхамо, Тензин, торговец, Долма); в `BP_InspectableBase` — переменная `ItemTag`; в `AC_InteractionComponent` — `CollectedItems` и запись тега при осмотре. Всё остальное создаём ниже.
